# Umsetzung

Etappen und Abnahmen stehen kanonisch im [Projektplan](PROJEKTPLAN.md), Abschnitt Etappen.
P0: Gerüste und Prozess. P1: Parität. P2: Treiber. P3: Tresor/Sync.
P4: durchgehender Ablauf. P5: persönlicher Client. P6: Teams. P7: Parität/Release.
P1, P2 und P3 werden nach P0 begrenzt delegiert; Architekturentscheidungen brauchen Befunde.
