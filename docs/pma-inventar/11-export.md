# Exportwege und Exportformate

Funktion, DB-System, Priorität, Plattform und Einordnung für Matrix-IDs stammen aus `docs/PARITAET.md`; alles andere ist Analyse bzw. Schätzung. SQL-Dump-Optionen sind in einer eigenen Datei geführt.
