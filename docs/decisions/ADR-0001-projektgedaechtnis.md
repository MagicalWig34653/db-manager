# ADR-0001: Repository als Projektgedächtnis

Status: akzeptiert durch Nutzeranweisung vom 20.10.2026.

Kontext: Sessions und Agent-Threads müssen ersetzbar sein.
Entscheidung: Maßgebliche Anforderungen, Entscheidungen, Status, Aufträge, Prüfungen und
Übergaben liegen im Repository. AGENTS.md ist gemeinsamer Einstieg; CLAUDE.md verweist darauf.
Agents arbeiten mit begrenzten Paketen und unabhängigem Review. Anbieterquoten entfallen.
Alternative: Chat oder persönliches Memory als Wissensquelle; erfüllt die Anforderung nicht.
Folgen: Dokumentationspflege ist Abnahmebestandteil; Handoffs dürfen keine Secrets enthalten.
