# Synthetische Platzhalter für API 0.17

Alle JSON-Dateien in diesem Verzeichnis sind **synthetische Platzhalter**, keine
Liveantworten und kein Prüfbeleg eines Datenbankservers. Kennungen, Benutzer,
Zeitpunkte, Identitätstoken und Hashes sind absichtlich erfunden. Die Nullen in
`plan_sha256` sind kein ausführbarer Planhash. Dateien mit `.invalid.json` müssen
vom Vertragswächter abgewiesen werden. Die Fixtures enthalten keine Zugangsdaten.
