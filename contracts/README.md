# Gemeinsame Verträge

Noch kein freigegebener API-Vertrag. Vor Implementierung definieren: Fähigkeiten,
SQL-Typen und Fehler, Abbruch, Streaming, Metadaten, Verbindungsherkunft und Authentifizierung.
Versionierte Verhaltensfälle sollen von Go- und Swift-Adaptern ausgeführt werden.
Clients benötigen einen festen Stand und dürfen ohne Geschwister-Checkouts baubar sein.
